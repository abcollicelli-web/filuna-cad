# Segurança

## O que este repositório faz no seu computador

- As habilidades são texto: ensinam o assistente, não executam nada sozinhas.
- Os validadores (`ferramentas/`) leem arquivos de malha e imagens que você indicar e escrevem só o arquivo de
  saída que você pedir. Não acessam a rede.
- Os scripts de exemplo geram arquivos na própria pasta.

## O conector do Filuna

- O endereço é `https://filuna3d.com/api/ia/mcp`. A ligação é feita pelo login do próprio cliente no Filuna, que
  escolhe o que permite e pode desconectar em Conta › Assistentes.
- Cada cliente só vê a própria conta. Imprimir exige confirmação em dois passos.
- Nenhuma chave ou senha fica neste repositório, e o assistente nunca deve pedir senha, chave de acesso ou
  código de impressora na conversa.

## Avisar de um problema

Escreva para o suporte da Filuna 3D pelo site [filuna3d.com](https://filuna3d.com), ou abra uma issue sem
detalhes sensíveis pedindo um contato privado.
